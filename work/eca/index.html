ПроектыДвижение ЭКА

Движение ЭКА

Десять лет арт-дирекшна крупнейшего экологического движения России: кампании, программы для бизнеса, образовательные проекты.

Клиент
Движение ЭКА
Отрасль
Экология / НКО
Годы
2014-2024
Услуги
Арт-дирекшн, Key visual, Брендинг

Задача

Держать единый визуальный язык десятков программ и кампаний, каждая со своей аудиторией: школьники, волонтёры, бизнес, госструктуры.

Решение

Выстроил систему брендов движения, вёл key visual федеральных кампаний, руководил дизайнерами и подрядчиками. Разрабатывал проекты КСО и ESG для партнёров: МТС, PepsiCo, Mars, Леруа Мерлен, Минприроды, Правительство Москвы.

Результат

  • Система брендов для программ движения
  • Key visual федеральных кампаний
  • Проекты КСО/ESG для крупных партнёров

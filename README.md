# GEOGLYF

Сайт мультидисциплинарного дизайнера Георгия Шустова: дизайн-поддержка по Time & Material и проектные услуги.

Статический сайт без сборки: `index.html`, `styles.css`, `script.js`, `assets/`.

## Запуск локально

```bash
python3 -m http.server 8080
```

Открыть http://localhost:8080.

## Деплой

Любой статический хостинг (GitHub Pages, Netlify, Vercel, Tilda «свой код»). Достаточно загрузить корень репозитория.

## Что заменить перед публикацией

- Обложки кейсов в секции «Проекты»: сейчас стоят заглушки `picsum.photos`, ссылки ведут на архив shustov.webflow.io.
- Ставку и вилки в секции «Поддержка», если они изменились.
- Форма контакта открывает Telegram с готовым текстом. Если нужен бэкенд, замените `action` формы на Formspree или Tilda-форму.
